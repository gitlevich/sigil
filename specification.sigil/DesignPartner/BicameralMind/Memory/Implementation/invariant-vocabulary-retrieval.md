# vocabulary-retrieval

#recognize-familiar-sigil finds the nearest remembered position to the current @shape and delivers the @sigil#name, @affordances, and @invariants attached to it. This is the vocabulary the @LeftHemisphere needs to generate sentences about the @sigil.

Without the vocabulary, the @LeftHemisphere has the @sigil#name but no constraints on what it can say. With the vocabulary, generation is bounded by what the @sigil actually means.

Violation: recognition returns a @sigil#name without @affordances and @invariants. The @LeftHemisphere receives a word with no meaning.
