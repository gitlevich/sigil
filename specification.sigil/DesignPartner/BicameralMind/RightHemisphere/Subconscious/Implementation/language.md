# Implementation

This is where we address the how of the @Subconscious.

The @Subconscious applies the @Relevance filter to @Experience. An @Experience segment is relevant when it exposes @affordances that can affect active @invariants. Segments without usable @affordances are not promoted to @Memory.

#filtering runs continuously on new @Experience as it arrives. #consolidate runs the same filter in bulk during idle time and between sessions. Same mechanism, different scope.

The @Subconscious never escalates to the @LeftHemisphere. It operates at the @RightHemisphere's resolution.

Acceptance criteria:

!affordance-relevance — selection is based on whether @Experience segments expose usable @affordances, not on geometric proximity alone

!single-mechanism — #filtering and #consolidate use the same @Relevance filter

!no-escalation — the @Subconscious never invokes the @LeftHemisphere
