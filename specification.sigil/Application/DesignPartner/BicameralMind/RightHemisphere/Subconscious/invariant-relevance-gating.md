# relevance-gating

Not all disturbance deserves attention. An edit's claim on awareness depends on whether it touches what the user is currently working on. The current locus of work defines a set of active @invariants and an active @shape. Edits that affect these rise. Edits outside the locus stay quiet — even if they are geometrically significant — unless they happen to affect an @invariant that the active work depends on.

This is a filter on delivery, not on detection. The mechanism still detects distant disturbance. It just does not surface it unless there is a dependency path from the disturbed region to the active locus.

Violation: an edit to a distant, unrelated part of the @sigil interrupts the user's current work with an alert. Or conversely: an edit to a distant part that breaks an @invariant the current work relies on goes unnoticed.
